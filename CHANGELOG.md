All notable changes to Slix are documented in this file. The project follows
[Semantic Versioning](https://semver.org/spec/v2.0.0.html) while allowing

## [Unreleased]

## [0.1.0] - 2026-07-29

### Added

- Initial fixed-length message parser with JSON, table, YAML, CSV, and raw output.
- Managed specification projects and project selection.
- Interactive Neovim parsing and plugin integration.
- Windows and Linux command-line support.
