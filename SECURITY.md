# Security Policy

## Supported versions

Only the latest published Slix release receives security fixes.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
**Security** tab and select **Report a vulnerability** to submit a private
report to the maintainers.

Include the affected version, operating system, reproduction steps, and likely
impact. Do not include real enterprise messages, specifications, credentials,
or other confidential data.
